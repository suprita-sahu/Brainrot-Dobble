# Brainrot Dobble 💀

A colorful, responsive meme-matching game built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in your browser. No install or build step is required.

## Deploy on GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. The URL will appear in the Pages settings.

The meme characters are represented by emoji and text, so the game does not depend on external image assets or APIs.
